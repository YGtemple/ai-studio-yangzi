# MiniMax H3 提示词适配器

本文件只负责把已经确认的镜头规划转换为 MiniMax H3 提示词，不负责改剧本或重新设计镜头。

官方来源：

- https://github.com/MiniMax-AI/MiniMax-H3
- https://github.com/MiniMax-AI/MiniMax-H3/tree/main/skills/h3-prompt-writing

## 模式判断

根据用户实际提供的参考自动选择，不要求小白学习英文模式名。正式流水线只允许带图模式：

- 纯文字：T2VA，仅限高手明确要求的非正式测试稿，不得登记为正式生成版本；
- 首帧图：I2VA；
- 首尾帧图：FL2VA；
- 只给尾帧：L2VA；
- 多角色、场景、视频或音频参考：Ref2VA。

不得同时把同一张图片既当身份参考又含糊地当作首帧。每个正式镜头必须绑定本镜实际分镜图或首帧图；每个素材都要说明角色、场景、构图、动作、声音或具体帧锚点职责。

## 小白默认：中文直投

MiniMax H3 官方资料说明模型稳定支持中文等 11 种对话语言。课程版默认给中国学员输出一条可直接复制的中文提示词，不强迫小白阅读英文标签。中文直投仍必须按顺序写清：

1. 镜头总时长与画幅；
2. 首帧构图、人物站位、场景和光线；
3. 按时间推进的动作、摄影机、表演与准确对白；
4. 环境声、动作声和配乐要求；
5. 角色、道具、轴线、口型和首尾帧连续性限制。

即使已经垫图，文本也必须完整写出人物相对地标的站位、身体状态、视线、道具、伤势、光源、屏幕方向与准确对白；不得让模型自己猜图片与前一镜的关系。

中文提示词不得写“上一镜头、继续、同上”。对白和画面文字保持用户原文；只有项目本身是 MV 或用户明确提供歌曲时才处理歌词。

## 进阶可选：官方结构兼容

只有用户明确要求“官方 H3 结构”“API 结构”“Context-IR 结构”，或实际接口需要固定字段时，才使用下面的官方结构。字段名和区块顺序保持英文，说明正文按该接口要求输出；中文对白与画面文字保持中文。

### 基础模式结构

I2VA、FL2VA、L2VA 先写官方对齐说明；T2VA 直接从三个核心字段开始：

```text
integrated_multimodal_description: [Shot 1] ... [Shot 2] At 00:03.500, ...

overall_soundscape: ...

non_diegetic_music: ...
```

官方结构兼容模式的说明正文使用清晰英文；对白和画面内文字保留用户原语言。第一镜头不写时间戳，后续镜头使用严格递增的 `At MM:SS.mmm` 切点。

说话者使用稳定的 `(S1)`、`(S2)`；对白格式为：

```text
<d>[Chinese] 用户确认的准确台词。</d>
```

不得翻译、润色或压缩台词。跨切、画外或截断必须使用官方连续性写法，但跨多个独立生成文件时仍要在每条提示词中完整声明实际台词和首帧状态。

### 多参考模式结构

Ref2VA 严格使用六段并保持顺序：

```text
subject_definitions:
<Subject 1> ...

summary:
[reference generation] ...

retention_analysis:
<Subject 1> ... fully_preserved - ...

detailed_description:
[Shot 1] ...
[Shot 2] At 00:03.500, ...

overall_soundscape:
...

non_diegetic_music:
...
```

角色、场景、道具、图片、视频和音频标签在六段中保持同一含义。参考素材顺序必须与平台实际上传顺序一致。

## 从镜头表映射

- 首帧硬描述、站位、动作、摄影机、时间轴和准确对白进入 `integrated_multimodal_description` 或 `detailed_description`。
- 环境声、动作声和非语言人声进入 `overall_soundscape`，不重复对白。
- 只有观众能听见的配乐进入 `non_diegetic_music`；没有就写 `N/A`。
- Lira 资产映射为 `<Subject N>`；实际关键帧映射为 `<Picture N>`；参考运动或剪辑节奏的视频才映射为 `<Video N>`；音色或实际音频映射为 `<Audio N>`。

## 与 Seedance 隔离

H3 中文直投可以使用自然中文段落，但不得复制 Seedance 的固定区块模板冒充同一种格式；官方结构兼容模式才使用 H3 的三段或六段英文字段。Seedance 输出不得混入 H3 官方字段。选择“双版”时分别输出两个独立代码块和两个独立文件。

## 本地工作流提醒

H3 的网页/API流程可能包含 Context-IR 提示词增强；完全本地工作流是否具备相同预处理取决于学员实际节点。Skill 不得声称本地结果必然等同网页端。没有工作流文件时只按官方提示词结构输出，不猜采样参数。
