## 二、景别公式（10 种句型）

### 公式 1：前进式句型（由远及近）
由整体到局部，引导观众逐步聚焦环境、人物与细节。
**句型**：远景/大全景 → 全景 → 中景 → 近景 → 特写
**应用场景**：开场、场景介绍、人物登场、线索发现、叙事推进
**节奏**：节奏平稳，循序渐进，代入感强

### 公式 2：后退式句型（由近及远）
从细节/情绪出发，逐步扩展到环境，释放情绪张力。
**句型**：特写 → 近景 → 中景 → 全景 → 远景/大全景
**应用场景**：情绪爆发后拉开、故事收尾、揭示式叙事
**节奏**：情绪渐退，意境升华，宏大感

### 公式 3：正反打中景+特写组合
中景交代位置，正反打展现情绪，特写放大情绪。
**句型**：双人中景 → 反打中景A → 反打中景B → 关键特写(眼神/特写)
**应用场景**：双人对话、对手戏、审讯戏
**节奏**：节奏紧凑，人物张力强，情绪变化清晰

### 公式 4：递进式情绪强化
景别不断收缩，放大表情与细节，强化情绪张力。
**句型**：中景 → 近景 → 特写 → 超特写（眼部/嘴部/手部）
**应用场景**：情绪爆发、紧张、紧迫、独白/喊叫、被吻前
**节奏**：情绪递进，压迫感强，层层递进

### 公式 5：两极镜头跳跃（远景↔特写）
跳过中间景别，而以极近/极远切换，制造冲击与反差。
**句型**：全景/远景 → 特写/超特写 → 全景/远景
**应用场景**：动作戏、冲击波、Jump Scare、战争灾难、节奏快、冲击力强

### 公式 6：动作流程公式
先交代环境，再展示动作，强化关键瞬间，镜头收尾。
**句型**：全景（交代）→ 中景（过程）→ 近景（细节）→ 超特写（收尾）
**应用场景**：动作、追逐、运动、事件推进、比赛瞬间
**节奏**：动作流畅，逐级逼近，张弛有度

### 公式 7：循环式句型（前进+后退结合）
由远及近聚焦情绪，再由远及远释放，形成情绪循环。
**句型**：远景 → 中景 → 特写 → 中景 → 远景
**应用场景**：场景、情绪、特写、时空切换、文艺片
**节奏**：节奏舒缓，情感流动，传递复杂内心

### 公式 8：过肩视角递进
以角色视角为引导，逐步推进，强化代入感。
**句型**：过肩中景 → 过肩近景 → 反打特写
**应用场景**：对话、心理、窥视、监视、审讯、亲密场景
**代入感**：代入感强，仿佛身临其境

### 公式 9：积累式句型（同景别重复）
用多个同景别细节镜头叠加，叠加信息密度。
**句型**：特写A → 特写B → 特写C → 全景
**应用场景**：蒙太奇、悬念叠加、紧张感、信息密集
**节奏**：节奏快，信息密集，让观众紧张感积聚

### 公式 10：主观视角 POV 公式
角色反应引出 POV 视角，视角切反应，强化代入感。
**句型**：角色反应特写 → POV 主观视角 → 角色反应特写
**应用场景**：第一人称视角、恐怖视角、偷窥视角、恐怖片
**沉浸感**：沉浸感强，身临其境

## 三、使用规则

1. **与运镜库的关系**：景别解决"画面框多大/从什么角度看"，运镜解决"镜头怎么动"——写镜头规格五要素时，景别+角度类=第二要素（拍摄视角+角度值），运镜方式=第三要素。如"近景·微仰背部越肩·跟拍·跟随红衣女子·0-3s"。
2. **公式选镜依据**：开场/人物登场→公式1（前进式）；收尾/情绪释放→公式2（后退式）；对话/审讯→公式3（正反打）；情绪爆发→公式4（递进收缩）；动作冲击→公式5（两极跳跃）；动作流程→公式6（动作流程）；文艺抒情→公式7（循环）；窥视/亲密→公式8（过肩递进）；蒙太奇/悬念→公式9（积累式）；恐怖/沉浸→公式10（POV公式）。
3. **景别与情绪的对应**：景别=情绪距离（远景=客观/史诗→特写=主观/情绪），景别越近情绪越紧、越远情绪越松；每条景别附「情绪功能」标签作选镜速查（如远景=孤独/渺小/史诗，特写=情绪爆发点）；公式4（递进收缩）和公式5（两极跳跃）是情绪强化的两大主力句型。
4. **正反打轴线规则**：公式3（正反打中景+特写组合）与公式8（过肩视角递进）使用时遵守轴线规则——两人连线为轴，机器在轴一侧 180° 内移动，不可越轴，否则观众方位感混乱。
5. **提示词直接可用**：本库每条的「提示词」为可直接复制进视频提示词的写法，使用场景标签作选景依据；公式句型可直接套用进分镜序列。
6. **跨库引用**：本库景别=情绪距离与导演顾问 shot_grammar 一致，互为补充（本库含英文术语/提示词可直用，shot_grammar 含 AI 生成时长建议）。
7. **参考图标注元素隔离铁律兼容**：本库为纯文本提示词库，无参考图标注层；若按本库景别生成时还使用了分镜图类参考图，仍按总控「参考图标注元素隔离铁律」剥离标注层。
