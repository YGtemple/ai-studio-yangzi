# 布光速查库（光线情绪·公开电影常识）

> 用途：08 CINEDANCE / 06 场景设计，用户说"要电影感/画面太平/光影不对/补个光"时，按本表选光位和光比，翻成提示词。
> 内容为电影摄影公开常识（三点布光、光位、高低调），非任何第三方付费课原文。
> 铁律：AI视频提示词不写"放三盏灯/主光在45度"这种设备指令，写成**光源方向、软硬、反差、色温、情绪**。

## 一、三点布光骨架（万能起点）

- **主光 key**：最亮的主光源，放主体前侧 30–45°、略高于眼平，塑造面部/物体立体感和主阴影。
- **辅光 fill**：对侧的柔光，亮度约为主光一半到三分之一（光比 2:1），只把死黑阴影提起来一点保留细节，别把阴影打没。
- **轮廓光/背光 backlight**：主体后上方，打出亮边，把人/物从背景里剥出来，加纵深。
- 三者齐备 = 干净专业的基础影调；缺辅光→戏剧硬阴影；缺轮廓光→人贴背景上发闷。

## 二、七种光位（按光源相对镜头方向）

| 光位 | 观感 | 适合 |
|---|---|---|
| 平面光（正面） | 平、亮、没褶子 | 美颜/记录感/喜剧，人显年轻但不立体 |
| 前侧光（45°） | 立体、自然 | 万能，人物最耐看 |
| 正侧光 | 半脸阴半脸阳，雕塑感 | 对峙、内心分裂、硬汉 |
| 后侧光/侧逆光 | 边缘发亮、脸隐入暗部 | 神秘、剪影、高级 |
| 逆光 | 轮廓金边、正面近黑 | 神圣、离别、剪影、人物从暗里走出 |
| 顶光 | 眼窝鼻下发黑、压迫 | 审讯、邪恶、阴森 |
| 脚光（自下往上） | 反常、诡异 | 反派/恐怖/噩梦 |

## 三、影调与光色（按情绪选）

- **高调 high-key**：整体亮、阴影浅、反差小 → 明亮、天真、喜剧、青春。
- **低调 low-key**：大面积暗、只亮局部、反差大 → 悬疑、 noir、夜晚、内心戏。
- **彩色光/有色光**：霓虹/青橙/单色调 → 赛博朋克、梦幻、情绪放大。
- **自然光**：窗光/天光/黄昏侧光 → 真实、纪实、温暖、生活流。
- **光比**：主辅比 2:1 偏自然舒服；4:1 以上偏戏剧硬朗；光比越大越戏剧。

## 四、提示词转写规则

✅ 写这些：
- "冷白顶灯从斜上方打下，脸侧有手机屏幕的暖反光，低调高反差"
- "窗光从右侧来，软光，阴影边缘模糊，整体暖调"
- "逆光勾出肩膀和发丝金边，面部留给暗部"

❌ 别写这些：
- "放一盏主光一盏辅光一盏轮廓光"（设备指令，模型不认）
- "f/2.8 三点布光"（焦段/布光术语模型不执行）

## 五、应用规则

1. **画面平**：先加反差（暗部压下去、给主光方向），别急着加更浅景深——平往往是没光比，不是没虚化。
2. **情绪不对**：从高调/低调/光色三选一切，比换景别更有效。
3. **跟导演速查联动**：维伦纽瓦=硬冷天光大反差；王家卫=霓虹色替情绪；泰伦斯马力克=自然天光仰拍；库布里克=干净硬阴影。
4. **一致性铁律**：同一场景全片主光方向和色温锁死，跟三锁库"锁场景"一起执行。
