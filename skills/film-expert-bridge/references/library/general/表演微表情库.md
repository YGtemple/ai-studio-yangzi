# 表演微表情库（让AI人物不像摆拍脸）

> 用途：08 CINEDANCE，用户说"表情假/僵硬/不像演员/情绪太浮夸"时，按本表把抽象情绪词翻成可拍的表演指令。
> 内容为表演与提示词工程公开经验，非任何第三方付费课原文。
> 铁律：**别写"他很伤心"，写"谁、为什么、用什么方式伤心"**——情绪词不是指令，身体反应才是。

## 一、情绪万能公式

`人物情绪 = 表情细节 + 手部动作 + 身体姿态 + 视线方向 + 说话语气`

五个维度同时给，AI 的情绪才立体；只给一个"难过"，出来就是摆拍脸。

反例："他很伤心地走开。"
正例："他垂着眼，嘴角绷着不说话，手攥着衣角，慢慢往后退半步，声音压得很低：'……我走了。'"

## 二、先给情绪一个"发生原因"

演员拿到戏先想"我为什么会这个反应"，不是先想"我做什么表情"。
提示词里要交代：**触发事件 + 人物此刻的动机/关系**。
- 同样一句"走开"，撒娇/嫌弃/愤怒/害怕/崩溃是完全不同的演法——把动机写进去，AI 才知道用哪种。

## 三、微表情粒度（别用大词）

| 部位 | 指令写法 |
|---|---|
| 眉 | 眉峰轻抬/眉心微蹙/眉心舒展 |
| 眼 | 眼神聚焦某点/眼睑微垂/瞳孔先定后移；**眼球动必带眼睑微动，否则像死鱼眼** |
| 嘴 | 真笑=嘴角上扬+上唇提升+下眼睑上提；假笑只动嘴角；抿嘴=压抑 |
| 呼吸 | 咽了一下/肩膀松下来/深吸一口气 |
| 身体 | 紧张攥衣角、害羞下意识捂嘴、压抑时喉结滚动、释然肩膀下沉 |

## 四、逐秒时间序列（情绪转折用）

情绪不是一帧到位，是变化的。把一段表演按秒拆开：
`0-1s 残留痛苦 → 1-2s 眼神放空 → 2-3s 表情收起 → 3-4s 身体停住`
按秒写状态变化，AI 不会情绪跳帧。

## 五、定妆照带"人生状态"

角色不是纸片人，定妆提示词里加状态痕迹：
"刚经历失败的人"→ 疲惫眼袋、略暗沉、轻微面部不对称；"长期焦虑"→ 眼下青、嘴角垮。
这些痕迹让人物像活过，不是模特。

## 六、应用规则

1. **表情假/浮夸**：九成是只写了情绪词，按公式补全五个维度。
2. **眼神空洞**：补视线落点（看哪/看谁）+ 眼睑微动。
3. **情绪转折戏**：用逐秒序列拆，不要一个"大哭到底"。
4. **跟台词去AI味库联动**：台词管"说什么怎么说"，本库管"脸上和身体怎么演"，一起用。
5. **跟三锁库联动**：脸靠参考图锁，表演靠提示词写，别让提示词重描长相。
