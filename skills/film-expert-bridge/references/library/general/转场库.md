# 转场库（用电影语言藏切点）

> 用途：08 CINEDANCE / 09 后制，用户说"镜头一剪就跳/像PPT/转场生硬"时，按本表选转场。
> 内容为剪辑与视听语言公开常识，非任何第三方付费课原文。
> 铁律：好转场是"观众没察觉切了"，不是堆特效。核心是利用运动/遮挡/动作的相似性把切点藏起来。

## 一、四种最常用（AI视频好实现）

| 转场 | 怎么做 | 提示词怎么写 |
|---|---|---|
| **遮挡转场** | 第一个镜头让门/墙/路人/树/物体从镜头前划过，画面被完全挡住的那一瞬间切到下一场景 | "前景一个人/车从左向右完全掠过画面遮住镜头，画面全黑瞬间切到下一场景" |
| **甩镜转场** | 镜头快速横摇/甩动，画面出现运动模糊，在最模糊的一帧切 | "镜头快速向右甩动产生运动模糊，模糊中切到下一镜，方向一致" |
| **动作匹配** | 两个不同时空用同一个动作接：抬手到最高点切，下一镜继续抬手接另一个动作 | "角色抬手推窗，手臂抬到最高点切；新场景同一方向继续抬手接住落下的纸" |
| **相似构图/图形匹配** | 下一镜主体在画面相似位置/相似形状，观众当作连续 | "新镜头主体仍在画面中心同一位置，承接上一镜构图" |

## 二、其他可用转场

- **空镜匹配**：上一场结尾留一个空镜（街景/物件），下一场从同类空镜进。
- **推近/拉远揭示**：推到主体切；或拉远揭示新空间。
- **闪白/光线**：过曝一亮切，用于时间跳。
- **焦点虚化**：前景变虚→切→新场景从虚变实。
- **声画延续**：下一场的声音先起，画面后到，切点藏在声音里。

## 三、什么时候别用转场

- 同场景对话、动作连续戏：硬切最干净，别加花哨转场。
- 转场本身不能抢戏——观众注意到"这个转场好炫"就说明过了。
- 别叠太多：一条短片两三种就够。

## 四、应用规则

1. **单镜都不错、一剪就PPT**：在切点前主动埋一个遮挡物或甩镜，别指望后期硬加。
2. **跟节奏库联动**：快节奏段多用甩镜/动作匹配；慢段用空镜/叠化。
3. **跟三锁库联动**：转场不能破坏人物/场景锁定；动作匹配要保动作方向连续。
4. **跟09后制联动**：AI生成时写好转场动作；实在没生成出来，后期走 mediakit 拼接/转场补救。
