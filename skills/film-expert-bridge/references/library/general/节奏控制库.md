# 节奏控制库（剪辑与镜头的呼吸感）

> 用途：08 CINEDANCE / 附加A 分镜，用户说"片子平/拖/赶/没节奏/像PPT"时，按本表定镜头时长和切换密度。
> 内容为剪辑与视听语言公开常识，非任何第三方付费课原文。
> 铁律：节奏是三变量共同决定——镜头时长、切换频率、镜头内部运动量，不是把镜头切短就叫快。

## 一、三个节奏变量

1. **镜头停留时长**（节拍器）
   - 0.5–2 秒：紧张、动作、冲突、追逐（快切造张力）
   - 4–7 秒：日常叙事、对话、交代（默认叙事段）
   - 8 秒以上：沉思、留白、情绪沉淀（慢切留余韵）
2. **切换频率**：切得越密越快；高潮快切每镜<1秒，抒情慢切每镜>5秒。
3. **镜头内部运动量**：镜头里人物/运镜本身动得快，等于外部节奏不切也快。

## 二、按情绪选节奏

| 情绪/场景 | 镜头时长 | 切法 |
|---|---|---|
| 追逐/争吵/悬疑 | 0.5–2s | 高频快切，动势强 |
| 日常对话/叙事 | 4–7s | 正常切，跟情绪走 |
| 抒情/告别/孤独 | 5–10s | 慢切，留空镜 |
| 高潮/爆发 | <1–2s | 最快切，堆密度 |
| 反转前 | 突然放慢/停顿 | 用气口制造预期 |

## 三、呼吸感原则

- **张弛有度**：不能一直快（观众麻），也不能一直慢（观众困）。快段后接一个停顿/空镜喘气。
- **短视频比电影快半拍**：前3秒必须用声音或特写抓住人，别慢悠悠铺垫。
- **变速和跳剪**：关键瞬间可变速（急慢/急停），制造呼吸和冲击。
- **声画匹配**：声音先到（下一段的声先起），动势延续，切点藏在动作里。

## 四、内/外节奏

- **内部节奏**：镜头里的动作速度、光影变化、音乐、人物情绪起伏。
- **外部节奏**：镜头之间怎么组接、切多密。
- 两者要同向：内部已经很激烈，外部就别再疯狂切；内部安静，外部也别硬切。

## 五、应用规则

1. **像PPT**：多半是每个镜头时长一样+镜头内没运动。变时长+加内部动作。
2. **拖沓犯困**：砍到2–4s，开头3秒上钩子（特写/声音）。
3. **眼花乱**：切太密没喘气，插空镜/停顿。
4. **跟转场库联动**：节奏定"多快切"，转场定"切点怎么藏"。
5. **跟三锁库联动**：分段成片时，段与段之间的节奏也要统一设计，别一段紧一段松。
