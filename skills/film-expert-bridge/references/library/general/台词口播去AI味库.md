# 台词口播去AI味库（05对白/07口播层）

> 用途：05剧本融合写对白、07 ACTING 写口播/台词提示词时，专治「AI腔」——太工整、太书面、每句都漂亮、没有活人说话的毛边。
> 与《情绪表达提示词库》分工：那份管「表演时脸/身体怎么动」，本份管「说出来的那句话本身怎么写才像人话」。
> 吸收自 doubao-human-signal 的故事/口播部分，已按影视台词场景收窄。

## 一、核心原则

- **保真第一**：只改「怎么说」，不改「说什么」。不丢情节信息、不改人物关系、不弱化关键台词。
- **去AI腔不等于口语化到底**：古装/正剧保留该有的文气，日常/口播才要碎。
- **人感是手段**：别为了像人加一堆无意义碎碎念、跑题、假细节。

## 二、对白（05 剧本层）

1. **潜台词**：人物说的 ≠ 想的。写「嘴硬的关心」「没说出口的转身」，别让角色把心里话逐字念出来。
2. **不每句都完整**：活人说话会打断、半句、答非所问、停顿、用动作代替话。
3. **人物声音可辨**：不同角色用词、句长、口头禅要拉开（对照02角色圣经的「声音可辨测试」），不能换个名字谁都能说。
4. **忌金句收尾**：不要每场结尾来一句升华/哲理/总结金句，留白比点题更有力。
5. **信息别一次倒完**：关键设定分批说，靠冲突逼出来，不靠角色开会念说明书。

## 三、口播/配音（07 与带货层）

1. **句子短**：口播每句 4–12 字为佳，长句必然拉低口型准确率。
2. **允许碎词**：就是、其实、你懂吧、对吧——这些是真人口播的呼吸，不是废话。
3. **忌排比押韵**：「高端大气上档次」式排比是广告腔，真人不说。
4. **语速偏慢**：AI 默认语速偏快，提示词里要写「语速偏慢、自然停顿」。
5. **说场景不说形容词**：「每次挤地铁妆就花了」比「持妆效果极佳」真。

## 四、AI腔症状→修法

| 症状 | 修法 |
|---|---|
| 每句都完整工整、像念稿 | 拆半句、加打断、答非所问 |
| 结尾必升华/金句 | 删掉金句，用动作或沉默收 |
| 角色说话一个味 | 按人设拉开句长、用词、口头禅 |
| 大词堆砌（赋能/极致/焕新） | 换成具体动作和具体场景 |
| 信息靠角色嘴念出来 | 改成冲突中带出、分批揭 |
| 口播太顺太押韵 | 拆短、加碎词、去排比 |

## 五、应用规则

1. **05 剧本**：对白写完过一遍本库，重点查潜台词、人物声音、金句收尾。
2. **07 ACTING**：口播台词同时按《配音语气提示词库》定音色，按本库定句子怎么写；嘴型提示再叠《真人感去AI味库》的口型同步补丁。
3. **只取台词层**：本库不做通用长文去AI味；文章/报告去AI味走 doubao-human-signal，不在此重复建设。
