# 导演审片返修库（生成后·质检与返修环）

> 用途：08 CINEDANCE 把提示词交给模型、视频生成出来之后，洋子V3此前只到"出提示词"就断了，本库补上**审片→判定→返修**这一后环。把"感觉假/不好看/不对"翻译成有时间点、有证据、有改法的导演意见。
> 吸收自 AI-Director-Video-Review v1.3 方法论，已按洋子V3体例重写。
> 铁律：不靠"感觉"打分；每个问题都要时间范围+可见证据+严重度+可执行改法；风格化/有意变化先按创作意图解释，不轻易判错。

## 一、三种工作模式（先定）

| 模式 | 用在哪 | 额外检查 |
|---|---|---|
| single | 一条视频独立质检 | 五维全查 |
| variants | 同一镜头多个候选版比选 | 逐条查完横向排名，比"谁完成了叙事任务"，不比谁更炫 |
| sequence | 一部连续作品多镜头 | 除逐条外，加查跨镜连续性（屏幕方向/视线/方位/光线） |

分不清 variants 和 sequence 且会改结论时，只问一个必要问题；否则按最合理假设并写进报告。

## 二、五维质检标准

1. **人物一致性**：脸型五官比例、发型发色、服装配饰、体型年龄、皮肤特征跨时间是否一致。遮挡/表情/透视/光照造成的合理变化不判错。重点：身份漂移、无因换装、局部器官重构、角色互换。
2. **动作连续性**：手脚位置、持物关系、动作起止、重心、碰撞、速度惯性。重点：物体凭空出现消失、肢体跳变穿模、不可能关节、交互断裂。剪辑点两侧结合切镜判断，不要求像长镜头逐帧衔接。
3. **场景一致性**：空间布局、建筑结构、道具数量位置、光源方向、天气时段。反打/视差/景深可改变表象。重点：固定结构漂移、关键道具消失、方位矛盾、无叙事依据的光线突变。
4. **摄影语言**：景别/构图/机位/运镜/焦点/曝光/色彩/节奏是否服务叙事。**不瞎编焦距数值**——没元数据就写"广角透视倾向""背景压缩感"，不写"24mm/85mm"。重点：主体不清、视线轴线乱、运镜无动机、焦点漂移、节奏情绪冲突。
5. **AI痕迹**：手指五官畸变、文字乱码、反射阴影矛盾、纹理爬行、边缘闪烁、物体融化、重复图案、背景人物变形。单帧错记时间点；闪烁漂移记起止范围；若低码率/运动模糊也能造成，降置信度并注明替代解释。

## 三、严重度四级

- `critical`：主体身份/叙事/可用性损坏，必须返修（单个 critical 可一票否决，哪怕总分高）。
- `major`：明显出戏或影响理解，建议返修。
- `minor`：可察觉但不碍核心表达，按发布标准定。
- `note`：优化建议或值得保留的优点，不算缺陷。

## 四、发布结论五种

- `ready`：可直接发，无必须修项。
- `post_fix`：简单剪辑/遮盖/字幕/后期后可发。
- `regenerate_segment`：需局部重生成或换镜。
- `reject`：核心主体或叙事系统性失效，整体重做更划算。
- `insufficient_evidence`：素材不可读/证据不足，暂不下判断。

## 五、评分（分三个独立结果，不拿一个总分掩盖）

- **技术质量**（100分）：五维各20分，从20扣——critical扣12–20、major扣5–11、minor扣1–4。
- **目标适配 goal_fit**（0–100）：是否达成用户目标和内容类型；没明确目标则为 null，不拿通用审美当目标。
- **证据置信度**：high/medium/low，反映素材可读性和上下文充分度。
- 风格/导演诊断**不混入**技术扣分；只有明确破坏叙事/发布用途时才影响 goal_fit。面部不可见/音频不可用/参考缺失的子项标"未充分检查"，不默认满分。

## 六、返修：选最低成本路径（从便宜到贵）

1. **剪辑规避**：问题在非必要头尾、重复动作、可删停顿。
2. **后期修复**：文字/Logo/水印/局部遮盖/声音/简单色彩/稳定。
3. **局部重生成**：短时间的脸、手脚、物体交互、纹理爬行、单一动作坏。
4. **整镜替换**：主体身份/产品结构/空间/叙事在大部分时长持续失效。

**只有跨全片系统性失效才建议整段重做**；否则优先最小范围返修。

## 七、每个返修包必含六项

1. 目标片段+建议保留的前后边界。
2. 要锁定的角色/服装/产品/场景/镜头特征。
3. 正向约束：明确期望的可观察结果。
4. 负向约束：只针对已观察到的问题，不堆通用负面词。
5. 方法建议：剪辑/后期/局部重绘/首尾帧约束/整段生成。
6. 验收点：返修后重新确认的 2–4 个可见条件。

**返修提示词模板**：
```
保留：{稳定参考帧中的角色、服装、场景、构图与光线}
动作：{动作起点、接触、运动路径、终点}
约束：{针对问题的稳定结构与连续关系}
避免：{本次实际发生的换脸/粘连/乱码/融化}
首尾：从 {起始状态} 自然过渡到 {结束状态}
```

## 八、关键判断原则（防误判）

- 区分"观察"和"推断"：素材确认不了的标待确认，不编镜头参数/比例/时间点。
- 区分"视觉效果"和"拍摄参数"：没元数据就描述倾向，不反推焦距光圈。
- 连续性至少比两个时间点；单帧缺陷可依单帧报。
- 风格化发光/变形/拖影/转场/变装**先按创作意图解释**，只有破坏可读性/时序/主体结构才判缺陷。风格本身不是缺陷。
- 不把"85mm必有情绪""浅景深必有电影感"当定律。
- 无法直接读视频时，不声称已审片；要视频/关键帧/带时间码截图。

## 九、应用规则

1. **位置**：这是洋子V3全流程的最后一环——08出提示词 → 模型出片 → **本库审片** → 按返修包改提示词 → 回08重生成，形成闭环。
2. **与09后制路由**：剪辑规避/后期修复类返修，路由到 mediakit（剪、遮、字幕、调色）；局部重生成类回08改提示词。
3. **多版本比选**：variants 模式不评"谁更好看"，统一按"是否完成同一叙事任务"打分排名，并给最佳版的返修提示词。
4. **TVC/全片**：除单镜头五维外，加查叙事（开头建情境/中间推价值/结尾收情绪）、品牌（露出自然无功能误读）、镜头节奏、声音同步、发布安全区。
