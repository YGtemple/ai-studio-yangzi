# 静图微动决策库（海报/插画/版式图动起来）

> 用途：用户给一张**已完成的静图**（海报、插画、拼贴、版式、封面、摄影作品、截图）要它「动起来/出个动态效果/图生视频」时，用本库判断该不该动、怎么克制地动。
> 与08 CINEDANCE 主动运镜分支并列：08管叙事镜头的推轨/跟拍/环绕；本库管**成品静图的微动**——原则是「最小动作让关系成立，别把一张好静图重画成另一部片子」。
> 吸收自 gc-still-image-motion-director，已中文化。

## 一、核心原则

动效必须从图片本身长出来，禁止套通用特效。
优先级：
1. 主体固有的动作（风吹头发、旗动、水流、火焰、眨眼、呼吸起伏）；
2. 这个动作带来的物理反应（头发动带起草屑、水花反溅）；
3. 前两者都不合适才用环境/观察层效果。

**禁止默认动作**：扫描光、漂浮呼吸纸、视差、粒子、镜头推近、通用电影感运镜。别让标本/石头/档案/安静物件硬演活物。一个有效答案可能是「这张图不该动」。

## 二、三态决策（先定态，再写动作）

| 态 | 含义 | 什么时候选 |
|---|---|---|
| motion | 一个明确的克制动作 | 主体本身有运动合法性（人物、水、火、风、旗、车流） |
| micro-motion | 几乎不动，只一点环境痕迹 | 主要是版式/海报/档案，只需呼吸感（树叶轻晃、尘粒飘、光缓移） |
| static | 干脆不动 | 静物标本、档案、已凝固的瞬间；说明为什么静止更对，可导出静图或只做极轻环境痕 |

**动作配额**：最多1个主动作 + 1个物理伴随动作 + 1个可选观察层效果。不准一次塞三个运动。

## 三、锁定清单（防文字/版式/边框漂移）

写提示词前先列「必须固定」：
- 文字、数字、标签、手写注释、纸张质感、边框、画框、网格、拼贴几何——全部锁死，不许漂移错位。
- 主体数量、身份、剪影、服装、比例、物体连接关系保持不变。
- 绳、把手、关节、柄、四肢、机械连杆保持连续。
- 海报/拼贴/档案/版式类**默认不要镜头运动**（不推不拉不绕）。
- 不要重复描述原图已经给的风格，多余风格词会诱导重绘。
- 不动的推荐结果：导出静图，或只加极轻环境痕迹，别硬造动作。

## 四、输出模板（一张图）

```
图片：[文件名/描述]
画面观察：[可见主体、构图、脆弱元素：文字/数字/边框/纸张/标注]
动态判断：[motion / micro-motion / static] — [一句理由]
建议运动：
  - 主动作：
  - 伴随动作：
  - 范围与路径：
  - 节奏与时长：
必须固定：[...]
不建议：[...]
可直接复制到视频模型：[完整提示词：主体+路径+范围+节奏+锁定+禁止项]
主要风险：[...]
```
用户只要提示词就只给提示词；空字段省略。未指定时长/模型时默认4秒静图微动，并说明这个假设。

## 五、一组图/文件夹

1. 先总结共同视觉系统；
2. 列出哪些约束可共用；
3. 每张单独判定 motion/micro/static；
4. 每张单独写提示词；
5. 主体行为不同时，不准说「一条通用提示词全包」。

## 六、交付前自检

- 动作是不是图片里看得见的东西引起的？
- 是不是只有一个主动作？
- 伴随动作是不是同一个物理原因？
- 所有脆弱设计元素（字/数/框/线）都明确锁了？
- 提示词写了范围、方向、节奏，而不是只说「自然动一下」？
- 镜头全程不动，结果成立吗？
- 有没有把每张图都套同一个特效？
- 拿不准的地方标了「不确定」，而不是把猜的当事实？

## 七、应用规则

1. **触发**：用户给成品静图要「动起来/做动态效果/图生视频/微动」时，先进本库定三态，再写提示词；不要上来就写推近/环绕。
2. **与08关系**：本库只产静图微动提示词；若要重新设计叙事镜头（多镜头、景别变化、走位），回08 CINEDANCE。
3. **与参考图标注隔离铁律**：静图若是分镜图/带标注工作稿，先剥标注层再动，标注元素绝不进成品。
