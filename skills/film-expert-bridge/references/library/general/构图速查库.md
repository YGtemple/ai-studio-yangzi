# 构图速查库（七种经典构图·公开电影常识）

> 用途：08 CINEDANCE，用户说"画面平/不知道主体放哪/要电影感构图"时，按本表选构图，翻成提示词。
> 内容为电影/摄影公开常识，非任何第三方付费课原文。
> 铁律：构图服务叙事——先问这个镜头要交代什么，再选构图；不为好看而对称。

## 一、七种构图速查

| 构图 | 怎么做 | 观感 | 适合 |
|---|---|---|---|
| **三分法/九宫格** | 画面横竖各分三等分，主体放四个交叉点，留点呼吸 | 自然、不呆板、万能 | 不知道怎么构图时的默认选择，占电影画面一半以上 |
| **中心对称** | 主体正中，左右镜像平衡 | 庄严、仪式、孤独、权威 | 韦斯安德森式、宿命感、权威/权力场面 |
| **引导线** | 用道路/栏杆/走廊/光带把视线引向主体或消失点 | 纵深感强、有代入 | 旅行、车行、大空间、视线需要被引导时；直线硬朗、曲线温柔 |
| **对角线/S曲线** | 主体沿对角或S形线安排 | 动态张力/韵律优美 | 运动、追跑、蜿蜒山路；S线偏优雅 |
| **框架式** | 用门窗/车窗/门框/树枝把主体"框"住 | 聚焦+暗示处境 | 窥视、围困、人物被环境困住 |
| **前景层次** | 镜头前放虚化的遮挡物（叶/栏杆/玻璃） | 沉浸、有空间厚度 | 增强纵深、第一人称窥视感 |
| **留白/负空间** | 主体挤在一角，大片空/黑/天 | 孤独、压抑、放空 | 人物渺小、失落、情绪留白 |

## 二、怎么选（按镜头任务）

- **交代人** → 三分法，别老怼正中间。
- **要仪式/权威/童话感** → 中心对称。
- **要把观众拽进空间** → 引导线或前景虚化。
- **要动起来** → 对角线。
- **要暗示人物被困/被看** → 框架式。
- **要孤独/渺小** → 留白负空间。
- **不知道选啥** → 三分法，不出错。

## 三、提示词转写

✅ 写这些：
- "三分法构图，人物在右侧交叉点，左侧大片负空间留给延伸的街道"
- "严格中心对称，主体压在画面正中，左右家具沿中轴排列"
- "走廊透视线从近景汇聚到尽头的人物，前景有虚化栏杆"

❌ 别写：
- "f/8 小光圈全景深对称构图"（参数模型不认，写视觉关系）
- 同一句里既要对称又要对角线（自相矛盾）

## 四、应用规则

1. **画面平**：先加构图层次（前景/引导线/留白），不是先加虚化。
2. **跟布光库联动**：构图定"人放哪"，布光定"光从哪来"，两个一起定。
3. **跟导演速查联动**：韦斯安德森=中心对称+平面化；奉俊昊=高低差/楼梯暗示阶层；朴赞郁=极度对称+镜面。
4. **别为构图牺牲叙事**：对称压过人物信息、引导线引错了重点，都是反效果；构图是手段不是目的。
5. **一致性铁律**：同场景同角色的景别和构图基调全片统一，不忽远忽近乱跳。
