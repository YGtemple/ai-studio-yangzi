# 大招模式连接器

> 目的：把项目里的三种模式彻底分流，避免大招模式误走普通对打/清兵链路。
> 当前版本：v1

---

## 1. 模式识别

当输入满足以下任一条件时，视为进入 **大招模式**：

- 头部为：`请帮我生成一条 xx 秒seedance直接可以生成的技能提示词，直接返回提示词就可以。`
- 模板中明确出现：`模式：大招模式（仙侠玄幻核心技能释放链路）`
- 字段结构中出现：`主角 / 反派 / 技能属性 / 属性细分 / 中段招式 / 后段大招`

---

## 2. 三模式分流

### 2.1 对打模式

满足以下任一条件时，继续走主项目对打链路：

- 头部为：`请生成Seedance2.0 xx 秒打戏提示词，直接返回提示词即可。`
- 模板中明确出现：`模式：对打模式（阵型对位链路）`

路由到：

```text
../seedance-combat-prompt/SKILL.md
```

### 2.2 清兵模式

满足以下任一条件时，继续走主项目清兵链路：

- 头部为：`请生成Seedance2.0 xx 秒清兵打戏提示词，直接返回提示词即可。`
- 模板中明确出现：`模式：清兵模式（阵型A清兵链路）`

路由到：

```text
../seedance-combat-prompt/SKILL.md
```

### 2.3 大招模式

当命中本文件第 1 节的大招条件时，必须停止使用普通打戏模板，切到大招专属链路：

```text
1. 先读 大招系统资料索引.md
2. 再按属性定位属性专项文件
3. 按需补读 国漫级大招设计语言库.md / 大招模版参考.md
4. 最后回到 大招主规则.md 组合正式输出
```

---

## 3. 大招模式输出约束

大招模式下，正式成品必须遵守：

- 输出两条：`大招提示词一` + `大招提示词二`
- 每条固定包含：`人物 / 场景 / 风格 / 分镜 / 细节强化 / 负面提示词约束`
- 不能套用普通对打模式或清兵模式的模板结构

---

## 4. 维护原则

1. 本文件只负责模式识别和链路分流，不承载完整招式池。
2. 大招规则主体统一维护在 `大招主规则.md`。
3. 新增属性或新招式时，先改 `大招系统资料索引.md` 与对应属性专项文件。
