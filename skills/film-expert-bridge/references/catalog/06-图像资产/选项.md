# 06 Lira 图像资产·增强选项

|---|---|---|---|
| A | 角色四面板参考图 | `../../modules/reference-art.md`、`../../modules/reference-art-source.md` | 有固定主要角色，需要锁脸、服装和状态版本 |
| B | 场景九宫格参考图 | `../../modules/reference-art.md`、`../../modules/reference-art-source.md` | 同一场景需要多机位、时段或空间连续性 |
| C | 故事板与一致性 | `../../library/general/image2故事板与一致性库.md`、`../../library/general/一致性硬控三锁库.md` | 多镜头连续叙事或多批次生图 |

| E | 构图与透视 | `../../library/general/构图速查库.md`、`../../library/general/透视与对比方法库.md`、`../../library/general/场景俯视图规范库.md` | 画面层级、空间尺度或视角关系重要 |
| F | 灯光与材质 | `../../library/general/布光速查库.md`、`../../library/general/真实质感提示词库.md` | 需要统一摄影棚光感或消除塑料质感 |
| G | 真人感 | `../../library/general/真人感去AI味提示词库.md` | 真人照片、短剧剧照或写实人物 |
| H | 古风场景资产 | `../../library/general/古风场景提示词库.md`、`../../library/general/古风场景三镜头模板库.md` | 古装、宫廷、武侠地点 |
| I | 静图微动预判 | `../../library/general/静图微动决策库.md` | 资产将用于图生视频，需要判断哪些细节可动 |
| J | 绘画参考检索 | `../../library/general/本机绘画参考库索引.md` | 用户明确要求使用本机参考库 |
