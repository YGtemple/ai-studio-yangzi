## 应用规则

1. 本文件只登记方法如何落到当前成果，不把审计文字混进角色、世界观或剧本正文。
2. 只有 `reference-memory.md` 中状态为“启用”且适用当前阶段的方法可以登记为“已采用”。
3. “已读取”不等于“已采用”。必须写出具体角色、关系、世界规则、场次、动作或对白落点；没有落点不得声称已经使用。
4. 参考方法与用户本轮要求或最新已确认项目事实冲突时，标记“待复核”并停止该项应用，不得覆盖项目事实。
5. 与当前任务不相关的方法可以不采用，但必须写清原因；不得为了证明调用而硬塞全部方法。
6. 用户确认阶段成果时，本应用单一并确认；跨阶段恢复以最新已确认成果和对应应用单为准。
