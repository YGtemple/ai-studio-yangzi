## 权威顺序

1. 用户本轮明确要求。
2. 当前项目最新、已确认的概念锚定、角色、世界观、分场和剧本文件。
3. 本文件中状态为“启用”且使用范围包含当前任务的参考方法。
4. 模型通用知识。

参考方法只能帮助表达已经确认的故事，不得反过来覆盖项目事实。发生冲突时停止并让用户选择。

## 使用规则

- 菜单只在项目首次相关创作前出现一次；选择前不检索。A 关闭，B/C 才检索，选择必须立即写入本文件。
- 只有用户明确确认采用的方法才能写入。写入时必须先保存，再继续当前创作。
- 每条参考使用稳定中文编号“参考方法001、参考方法002”。不得因聊天变长而改号或丢失。
- 使用范围固定为：故事创作（01-05）/ 图像资产（06）/ 表演（07）/ 视频镜头（08）/ 全流程（01-08）/ 指定阶段。
- 参考剧本，以及结构、主题、角色、世界观、分场、场景、对白方法，默认使用范围为“故事创作（01-05）”。进入 05 时必须加载全部启用的故事创作方法。
- 每条故事方法还要填写“阶段适用图”和“本阶段具体落点”。人物、关系与人物弧方法至少检查 02 和 05；世界规则、地点、阵营与物件方法至少检查 03 和 05；结构、场次、动作与对白方法至少检查 04 和 05。适用不等于强制套用，当前成果确实无对应内容时记录未采用原因。
- 每个阶段开始前先读取完整本文件，再按使用范围筛选。已有已确认方法时不得因聊天记忆不足而重新匹配新影片。
- 需要精确动作、场面、对白、镜头或方法时，按条目中的本地路径和页码再次定向检索，不凭聊天记忆补写。
- 用户可以随时增加、采用、停用、恢复、删除或替换参考。普通“删除”改为“已停用”并保留记录；只有“永久删除记录”才移除条目。
- 每次变更必须立即写入本文件，并追加到“参考变更记录”，然后才能继续创作。
- 旧项目若仍使用“适用阶段”旧字段：故事类条目即使只标了 `01`、`04`、`01/04` 或其中部分阶段，也自动迁移为“使用范围：故事创作（01-05）”并写回；不得在 05 静默丢弃。明确属于图像、表演或视频镜头的方法分别迁移到 06、07、08。
- 上游故事修改后，与修改内容冲突的条目标记为“待复核”，不得静默继续使用。
- 02、03、05 生成成果时，必须同时创建 `00_project/reference-applications/<阶段>-<成果版本>.md`。只有写出具体落点才算真正采用；“读过参考记忆”不能冒充已经融合。
