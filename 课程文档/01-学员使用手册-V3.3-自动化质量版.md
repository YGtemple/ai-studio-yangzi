# 本地知识库从剧本到视频提示词 V3.3 学员使用手册

## 先说结论

这是上一期“本地知识库从剧本到视频提示词 V2”的正式升级版，不是另起一套流程。非常感谢多名粉丝反馈原流程好用，还把自己整理的 Skill 工作流分享给我。收到以后，我没有把它们一股脑塞进系统，而是重新拆分、测试、归类，再深度融合进原来的 9 Skill 流程。

这次以粉丝贡献的 50 多套 Skill 工作流为扩展来源，又加入我们针对真实测试问题重新设计的调用规则，最终整理成 **11 个主流程 Skill、71 个可选择的技能分支**。这些分支不是原样堆叠，而是经过拆分、去冲突和阶段化改造。我的目标只有一个：让一个人也能像专业影视团队一样，从剧本、角色、资产、表演、分镜一路做到视频提示词和成片制作。这套流程还会根据大家的真实反馈持续优化；这一版比较狠，我也继续免费回馈给大家。

- 不选择新增技能：原来的 9 Skill 流程照常运行。
- 选择新增技能：只读取当前选中的专项，不把 50 多套资料全部塞进上下文。
- 已安装旧版：直接覆盖安装，不用换知识库路径，不会覆盖旧电影项目。
- 第一次安装和老学员升级：都只需要同一个全平台 ZIP，没有第二个版本。
- 角色圣经、世界观和正式剧本会把已经确认的本地参考继续用下去，并另存一份“参考用到了哪里”的记录，不会只说读过却没落实。
- 进入视频阶段后，每个正式镜头都要绑定自己的分镜图或首帧图；系统自动检查人物站位、轴线、动作、光影和地标连续性，再输出提示词。

## 一套包里有什么

安装后共有 11 个主 Skill 文件夹，电影创作仍按原来的 01 至 08 阶段推进。粉丝贡献的 50 多套 Skill 工作流已经被整理成 71 个阶段技能分支，不是让你额外安装 71 次，也不是让 71 项同时运行。

1. 总控路由
2. 01 概念锚定
3. 02 角色圣经
4. 03 世界观，可跳过
5. 04 分场大纲
6. 05 剧本深度融合与专业排版
7. 06 Lira 图像资产
8. 07 ACTING 表演
9. 08 CINEDANCE 镜头规划与视频提示词
10. 本地知识库桥，可选
11. 专家增强桥，可选

本地知识库桥负责“从你自己的剧本和影视方法书中找证据”；专家增强桥负责“把专项方法交给当前阶段使用”。两个桥互不强制开启。

## 新学员安装

### Codex 豆包 千问 OpenCode

把同一个完整 ZIP 交给具备电脑文件权限的 Agent，然后说：

> 安装我刚下载的完整课程包，自动解包并安装全部 Skill；安装后告诉我结果。

Codex 会安装全局 Skill。豆包工作模式、千问工作台和其他本地 Agent 读取同一套 `skills/` 与总控规则。出现本地文件或命令权限提示时，需要允许；普通网页聊天没有电脑文件权限，不能完成本地安装和检索。

OpenCode 如果当前配置不能直接读 ZIP，就把这同一个 ZIP 完整解压，再打开根目录并让它读取 `AGENTS.md`。不是另一个版本，只是同一包的打开方式不同。

## 老学员覆盖升级

老学员不用卸载，也不用重新开电影项目。把新版 ZIP 交给 Agent 后说：

> 覆盖安装新版课程包。先备份同名 Skill，保留我原来的本地知识库配置，不要修改任何电影项目。

安装器会先备份旧 Skill，再安装 11 个新版 Skill。已经配置的 `knowledge-base.json` 会被保留，所以知识库仍指向原来的文件夹，不用重新选路径。

电影项目与全局 Skill 是两套位置。覆盖安装只更新全局 Skill，不会删除或覆盖旧项目里的剧本、大纲、角色卡、资产、表演、镜头和历史版本。

旧项目继续使用时，在原项目对话里说：

> 升级当前电影工程到新版规则。只补控制文件和空目录，不覆盖任何创作内容。

## 知识库路径要不要换

不用。知识库可以在 Windows 任意磁盘、Mac 任意文件夹或外接硬盘，不会写死成老师电脑的 `G:` 盘。

第一次配置时说：

> 配置本地知识库：我来选择存放剧本知识库的文件夹，请自动完成路径配置，以后所有电影项目共用。

以后系统先读本机配置，再去这个学员自己的知识库检索。资料库 ZIP 必须先完整解压；课程安装包只有一个，支持读 ZIP 的 Agent 可直接接收，不能读 ZIP 的 Agent 解压同一个包后使用。

## 为什么现在会主动问一次知识库

很多新手不知道要说“调用本地知识库”，所以 V3 修复为：新项目确认从零开始、已有剧本或高手镜头模式后，在第一份创作成果生成前主动显示一次：

> 【本地知识库，可选】A. 不调用，照原 9 Skill 流程；B. 智能匹配 3 至 5 部本地剧本和方法书；C. 只查本地方法书。

- 选 A：不检索，原流程照常运行。
- 选 B：系统根据你当前故事自动找 3 至 5 部最相关剧本和方法书，不要求你先懂电影名。
- 选 C：只查编剧、导演、表演等方法书，不参考其他剧本。
- 选择前绝不检索；选择会写进项目，同一项目后面不重复问。
- 以后想改，可以直接说“这一步改用知识库 B”或“关闭本地知识库”。

## 新增技能怎样出现

每个阶段第一次进入技能选择时，系统先根据你的剧本、场次和当前任务，把最匹配的 1—3 项放在最前面标为“智能推荐”，然后显示这个阶段的完整菜单。菜单只显示技能名称和用途，不会一次读取几十个资料文件；你可以单选、多选、回复“照原流程”，也可以直接说出自己的想法。例如：

> 【智能推荐】导演顾问——先锁定整场拍法；人物站位连续——防止人物方向和位置跳变。下面同时显示本阶段完整菜单。

你不选，系统就照原流程继续，而且同一阶段不会重复问。08 的第一次选择会保存成整个项目的默认，换到下一场不会再把完整菜单弹一遍；只有突然出现此前没有的打戏、大招或复杂调度时，才会补一行建议。你也可以直接点名：

- 显示本阶段完整技能菜单，并智能推荐最适合我剧情的三项。
- 不用专家增强，照原流程继续。
- 选择多个技能，例如：导演顾问 + 人物站位连续 + Seedance 2.5 精细适配。
- 作者自定义：直接说“我想把这一场拍得像审讯，但不要警匪片套路”。系统先匹配已有技能；没有完全对应的，就只为当前项目建立一张自定义方法卡，不会擅自改动全局 Skill。

## 这次把哪些 Skill 融进了原流程

这 71 项不是 71 个步骤，更不是让学员背编号。原来的 9 个 Skill 仍然负责从故事到视频提示词；新增技能像一个专业团队工具箱，只在所属阶段出现。

| 你现在正在做什么 | 新增技能会帮你什么 | 学员最后能看到什么 |
|---|---|---|
| 想故事和定方向 | 保住作者审美、匹配合适的导演视觉、处理跨题材、国漫仙侠或真人短剧方向 | 一份更明确的故事定位，不会为了视觉效果乱改剧情 |
| 写人物 | 补宫廷、市井、现代群像、男女造型和战斗身份方法 | 人物外形、职业、说话和行动能区分开，后面生图不容易同脸 |
| 做世界观 | 补地点体系、法术属性、战斗空间和大招规则 | 能力有来源、代价和边界，场景不再每次随机变化 |
| 做分场大纲 | 补每场时长、戏剧任务、人物进出、转场和动作因果 | 后面拆镜知道这场要讲什么、预计多长，不会一股脑平均切镜 |
| 写正式剧本 | 让台词更像人说话、区分角色语气、检查穿帮、写清动作和大招结果 | 05 仍然是专业剧本，不会提前变成视频提示词 |
| 用 Lira 做资产 | 增加角色 2×2 身份卡、场景九宫格、故事板、白模、构图、灯光和真人质感 | 得到能锁人物和场景的生产资产，不把设定图误当最终镜头 |
| 用 ACTING 做表演 | 增加微表情、情绪行为、自然口播、配音、声音和受力表演 | 台词时长、呼吸、停顿、反应和动作重量能真正进入镜头 |
| 用 CINEDANCE 做镜头 | 增加内含镜头语言工具的导演顾问、空间连续性、打戏、大招、特殊运镜、审片返修和 Seedance 2.5 | 先确认怎么拍并保存镜头清单，再单独输出 Seedance 2.5、Seedance 2.0 或 H3 提示词 |

完整的 **71 项技能融合调用表** 已放在本手册最后。表里写清楚每个技能适合什么剧情、核心作用和调用后会产出什么；需要时查当前阶段即可，不用一次学完。

### 分场大纲里的时长会不会白做

不会。04 写的是“这场戏应该占多少时间”的预算，不是最终秒数。进入 05 写成正式剧本后，系统必须根据新增对白、动作和停顿自动生成一份成稿时长复核：误差在 10% 或 5 秒以内就直接登记；明显超出时才请作者决定删台词、拆场或放宽预算。07 再补演员自然说话、呼吸、反应和动作时间，08 才把最终可执行时长拆进镜头。完整顺序是：`04 场次预算 → 05 成稿自动复核 → 07 表演时长 → 08 最终镜头时长`。所以 04 不会白做，它是后面发现剧本越写越长的比较基准。

学员不用记任何内部编号，只要看中文技能名称和用途，也可以直接回复技能名称。以正式剧本阶段为例：

- **台词像人说话**：删除说明书式台词，补真实回应、停顿和话外之意。
- **每个人说话不一样**：按身份、关系、欲望和防御方式区分角色语气。
- **前后不能穿帮**：核对道具、伤势、时间、站位和信息。
- **动作写得能拍**：把“激烈打斗”变成能表演、能拍摄的动作因果。
- **大招必须推动剧情**：能力、代价、人物选择和结果必须进入故事。
- **真人表演质感**：校正动漫式、机械式反应，补生活细节和真实动作幅度。

如果系统只给出字母或数字而没有中文名称和用途，直接说：`请用中文重新显示本阶段技能菜单，写清每个技能解决什么问题，我只按名称选择。`

## 到了 CINEDANCE 学员实际怎么操作

现在的 08 不是把剧本一丢就直接吐提示词，而是按下面顺序走：

- 第一步：系统先读当前场次，主动推荐最需要的镜头、导演、打戏或大招增强，只显示名字和用途。
- 第二步：学员直接回复“用推荐的”“看看其他技能”或“照原流程”。
- 第三步：系统在聊天里先给出整场“怎么拍”的表，包括每镜为什么存在、用什么景别、从哪个角度看、人物怎么站、镜头动不动、光怎么变、什么时候切。
- 第四步：学员可以直接说“第 3 镜改近景”“这里不要环绕”“保留固定镜头”。系统修改后再次展示。
- 第五步：学员确认镜头表后，为每个镜头放入对应分镜图或首帧图。文件名带镜头编号时系统会自动对应；对应不清楚时只问一次。
- 第六步：系统读取前后分镜图，结合门窗、桌椅、楼梯、路灯、建筑和主光方向检查站位、视线、动作方向与 180 度轴线。能看见摄影机绕轴、人物转身或中性过渡就算合理换轴，不会误判成错误。
- 第七步：图片和连续性都通过后，系统才输出 Seedance 2.5、Seedance 2.0 或 MiniMax H3 提示词。H3 只是 CINEDANCE 内置的一个输出格式，没有第二个 H3 Skill。

## 导演顾问到底给学员什么

原来的 CINEDANCE 能写视频提示词，但没有把景别、角度、构图、光线、运镜和切镜理由做成一个必须先给用户确认的完整拍法环节。这次增加的导演顾问内含镜头语言工具箱，就是补上这一步。

它不是只在最后告诉你“镜头重复”。真正作用是：提示词出来以前，先让你看到每个镜头怎么拍并参与修改。“连续三镜相同”的风险标记只是最后质检，不是主要功能。

固定镜头不是错误。压迫、等待、尴尬、观察或完整表演需要固定时可以保留，但必须写清楚为什么不动；需要运动时要写清摄影机从哪里开始、跟谁、往哪里走、在哪里停。

只要记住两个角色：**导演顾问**用内置镜头语言工具设计整场拍法；**CINEDANCE**把确认后的拍法整理成正式镜头清单，检查时长和连续性，再翻译成视频模型提示词。

小白只要说：

> 进入 CINEDANCE，先和我确认这场怎么拍。把每镜景别、角度、构图、光线、运镜或固定理由、切镜理由给我看，确认后再出提示词。

## 两个最实用的专项怎样接原流程

### 角色与场景参考图

它与 Lira 不冲突。Lira 先根据最终剧本、角色卡和世界观决定需要哪些角色、场景和道具；参考图增强再把已确认资产整理成角色四面板、场景九宫格、站位图或白模预演。这里的白模不是要求学员进入 Blender 建模，而是先用图像模型生成 AO 黏土白模分镜、铅笔空间草图或站位示意图，低成本检查人物位置、遮挡、构图和机位。会 Blender 的进阶用户也可以用真实三维预演图替代，但不是必选步骤。

正确口令：

> 启用角色四面板参考图，仍以 Lira 已确认的角色资产为准，不增加新身份和新服装。

> 启用场景九宫格参考图，锁定入口、地标、主光方向和可用机位。

参考图是资产资料，不自动等于某个镜头的构图。V3.3 的正式流程要求每个镜头都有自己的分镜图或首帧图：同机位连续动作可以用前一镜尾帧；换角度、焦段或构图时，要重新生成或编辑当前镜头的新机位图。新图可以换机位，但人物相对地标的位置、动作、视线、道具、伤势和光线状态必须接得上。

### 导演顾问放在什么位置

导演顾问正是负责“先和用户设计镜头语言”的模块。它不是新阶段，也不是代替 CINEDANCE。它是 08 阶段里的可选前置步骤：先提出“这场戏为什么这样拍、谁在争什么、权力在哪一刻变化、景别怎么推进、机位和运镜怎么变化、每次切镜的理由”；用户可以在聊天中逐镜修改，确认后再由 CINEDANCE 根据最终台词、ACTING 表演时长和资产状态完成正式镜头清单与连续性。镜头清单确认后，才单独生成视频提示词。

选择导演顾问时：`导演顾问定拍法 → 你确认 → CINEDANCE整理并保存正式镜头清单与空间图 → 你确认 → 自动绑定每镜分镜图并做连续性质检 → 单独保存视频提示词`。

不选择导演顾问时：`CINEDANCE直接拆镜 → 你确认 → 自动绑定每镜分镜图并质检 → 输出视频提示词`。

正确口令：

> 先用导演分镜顾问提出拍法，再交给 CINEDANCE 完成正式镜头规划。

ACTING 仍负责台词速度、呼吸、停顿、反应和动作表演。导演顾问不能替它随意压缩台词，也不能直接越过 CINEDANCE 输出成片提示词。

如果你选择导演顾问，系统会先把镜头方案保存并让你确认。确认后 CINEDANCE 可以补时长、对白容纳、资产引用、首尾帧连续性和模型参数，但不能偷偷改掉镜头顺序、核心机位、核心运镜与切镜理由。确实无法执行时必须先告诉你哪里冲突，由你决定怎么改。

## 这次检查并修掉的逻辑问题

- 镜头语言工具不再作为另一个助手，而是直接放进导演顾问内部。
- 镜头语言与 CINEDANCE 只弹一次合并菜单，不会重复询问两遍。
- 连续 3 镜相同景别、相同角度且均为固定机位时，系统必须提醒重复风险。
- 固定镜头可以有，但必须有剧情理由；运镜也必须写清起点、目标和终点，不能只写“电影感运镜”。
- 导演顾问方案确认后会锁定，CINEDANCE 不能另写一套把它覆盖。
- 打戏和大招以前需要用户知道模块名字才能点名；现在场次命中后会主动推荐，但用户确认前绝不加载正文或输出提示词。
- 导演顾问把镜头语言从“生成后查重复”改为“生成前先设计、聊天中可修改、确认后再编译”，重复风险只保留为兜底质检。
- CINEDANCE 先核算对白、呼吸、停顿、动作和反应时长，再生成 Seedance 2.5、Seedance 2.0 或 H3 提示词。
- 三种模型格式分别输出，不能混写在同一条提示词里。
- 每个正式镜头必须有本镜实际分镜图和完整文字描述两层保险。图片负责构图与可见状态，文字把人物站位、动作、光影、道具和台词写完整，不能只写“接上一镜”。
- 系统会同时看前后图片中的地标与主光方向，再结合场景空间图检查轴线。证据不足就让你确认，不会武断改机位。
- 已确认的本地参考方法会在角色、世界观和剧本阶段继续使用，并保存具体应用位置；项目事实始终高于参考方法。

## 打戏和玄幻大招怎样用

学员不需要提前知道模块名字。进入 08 后，只要当前场次明确有对打、清兵、追杀、兵器交锋或体术，系统必须主动提醒：

> 检测到本场是打戏。推荐启用常规打斗框架、最匹配的兵器或徒手方法，并自动进行打斗自检。A 启用推荐，B 查看打斗细分，C 不用增强。

用户选 A 以后，打戏增强先把攻防关系写清楚：谁先攻、攻击方向、对方怎么闪挡接化、力量怎样改变重心、下一招为什么能发生。它不能改剧情胜负，也不能只堆“高速对打”和运镜词。

> 这场启用打戏增强，不要改剧情、人物能力和胜负；先给我动作编排卡，再交给 CINEDANCE 拆镜。

当前场次明确出现属性大招、终结技、镇压或封印时，系统也必须主动提醒：

> 检测到本场有玄幻大招。推荐启用大招五段链和当前角色属性专项。A 启用推荐，B 查看属性细分，C 不用增强。

用户选 A 以后，大招增强先核对角色属性、代价、场景和剧情结果，再写前摇、聚能、释放、对抗、结果五段链。

> 启用玄幻大招增强，先核对已确认的属性、代价和剧情结果；不要临时增加新能力。

两种专项都遵守同一个顺序：`系统主动推荐 → 用户选择 → 先看动作或大招方法卡 → 再看完整拍法镜头表 → 用户确认 → 绑定分镜图并质检 → 最后输出提示词`。用户选 C 就照普通 CINEDANCE 继续。第一次选择会保存为项目默认，换场不重复完整菜单；只有新场次出现默认没有覆盖的专项时才补一行建议。

## 镜头没做好怎么返回修改

直接说“回到镜头清单，修改第几镜”。系统先修改镜头清单，不会直接覆盖已经做好的提示词。新镜头清单确认后，只重新生成受影响镜头的提示词；没有受影响的镜头继续保留。

V3.3 会先把修改保存成新的镜头清单草稿。你确认新版以后，旧提示词就停止使用；换过的分镜图也会让对应镜头重新质检。系统只重做改动镜头和受影响的连续区间，没改的镜头继续沿用。多个 Agent 测试同一个电影项目时不要同时写入，避免版本打架。

## 常用口令

### 原流程

- 从零开始：我要做一部……
- 我有完整标准剧本：先读全剧本，保持原文不变，告诉我还缺哪些生产资料。
- 我有部分资料：先检查现有文件，告诉我最短补齐步骤。
- 高手模式：只优化这个资产、这段表演或这个镜头，不重跑整套流程。

### 本地知识库

- 调用本地知识库。
- 知识库 B：智能匹配 3 至 5 部剧本和方法书。
- 知识库 C：只查方法书。
- 整理新剧本并更新知识库。

### 新增技能

- 显示本阶段完整技能菜单，并智能推荐最适合我剧情的三项。
- 先用导演分镜顾问提出拍法，再交给 CINEDANCE 完成正式镜头规划。
- 选择导演顾问 + 人物站位连续 + Seedance 2.5 精细适配，我确认导演方案后再输出 Seedance 2.5。
- 作者自定义：先匹配现有技能，没有完全对应的就为当前项目建立方法卡，等我确认后执行。
- 关闭本阶段专家增强，照原流程继续。
